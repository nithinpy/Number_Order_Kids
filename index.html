📡 Home Wi-Fi Hosting Guide

1. Serve this app on your Home Wi-Fi (Node.js)

Run in the folder containing index.html:

npx.cmd http-server -p 8080 -a 0.0.0.0 --cors

2. Allow Ollama LAN Access (Windows PowerShell)

$env:OLLAMA_HOST="0.0.0.0"; $env:OLLAMA_ORIGINS="*"; ollama serve

Mac / Linux Terminal:

OLLAMA_HOST=0.0.0.0 OLLAMA_ORIGINS="*" ollama serve

3. Play on Any Tablet or Phone

Open http://YOUR-LAPTOP-IP:8080 in Chrome or Safari on any device connected to the same Wi-Fi.
